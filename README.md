<b>What is the Student Mentorship Platform?</b>

> The Student Mentorship Platform solution provided to solve the mentor gap problem is developing a Student Mentorship Platform, where students can connect online with a peer or an industry professional who can provide 1-on-1 guidance helping them gain confidence, and to fill in missing knowledge gaps in their learning journey.

## Getting started 

In the command prompt, type: 

<code>npm install-all</code>

<i>this will install all required dependencies for both the front end and backend systems.</i>

Next, type:

<code>npm start</code>

<i>this will concurrently run both the backend and frontend, complete application.</i>

<b>The application will be successfully running at address http://localhost:3000/</b>

Optional:

<code>npm dev</code>

<i>this will run the development version.</i>
